# Project workflow

The user requests that every completed change or addition be committed and pushed to https://github.com/AmitShok/chicken-punch.git.

After implementing and checking a change, commit it with a descriptive message and push to the configured upstream. Preserve unrelated work and remote history; do not force-push. If a push fails, report the reason and keep the local commit.

Preserve the game's existing pixel-art style. Reuse downloaded assets where suitable; create missing raster assets in Aseprite and retain the editable sources.
